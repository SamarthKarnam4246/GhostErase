## Working assumptions

The active API stores metadata at `backend/data/ghosterase.sqlite3`, uploaded source files under `backend/data/uploads`, and ChromaDB data under `backend/data/chroma`. Chroma queries, deletion, and residual checks use public collection APIs. Operation/check records store document/chunk IDs and sanitized result evidence, never document text. SQLite content is cleared only after all preceding source/vector/retrieval checks pass; failed or unavailable steps prevent a successful operation status and retain the SQLite content for recovery.
